# Руководство по Rift Atelier

Менеджер текстур, моделей и звуков Dota 2 для Windows x64. Можно собрать несколько наборов замен и переключаться между ними. После установки профиля приложение можно закрыть.

## Скачать модель

1. В меню слева откройте **Dota2PornFx** → **Модели**. В окне Rift Atelier появится официальный каталог с авторскими изображениями модов. Через «Предметы» и «Звуки» можно перейти в соответствующие разделы. [Официальный каталог](https://h6rd.github.io/Dota2PornFxWeb/)
2. Выберите мод и запустите его загрузку на странице. После проверки Rift Atelier добавит скачанный ZIP или VPK в библиотеку. Пакет из одного VPK сразу включится в текущий профиль. Если в архиве несколько вариантов, включите нужные в библиотеке.
3. Если у вас уже есть прямая HTTPS-ссылка на файл, нажмите **Скачать по ссылке**, вставьте адрес ZIP или VPK и выберите **Скачать и добавить**. Если ссылка ведёт на страницу описания, откройте мод во встроенном каталоге и нажмите его кнопку загрузки.

Каталог использует Microsoft Edge WebView2 Runtime. Если страница не открывается, можно воспользоваться прямой ссылкой или выбрать уже скачанный файл. [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)

## Первая замена

1. Запустите `RiftAtelier-1.3.exe`. Приложение найдёт Dota 2 в библиотеках Steam. Если игра не найдена, откройте «Настройки», нажмите «Обзор» и укажите `game\bin\win64\dota2.exe`. Можно также ввести путь к папке `dota 2 beta` вручную. Нажмите «Сохранить настройки».
2. Добавьте свой файл в библиотеку. Для отдельного ресурса найдите цель по имени героя или предмета. Например, запрос `axe armor` в категории моделей находит `models/heroes/axe/axe_armor.vmdl_c`. Для VPK пути уже заданы внутри пакета.
3. Включите нужные ресурсы в профиле. Если две замены указывают на один игровой путь, приоритет получит нижний элемент списка на странице «Профили». Порядок меняется стрелками. Изображение можно проверить в предпросмотре, исходный WAV — прослушать.
4. Когда закончите матч, полностью выйдите из Dota 2. Укажите в настройках Rift Atelier язык озвучки игры. На главной странице или в библиотеке нажмите **«Применить в Dota 2»**. Приложение соберёт VPK, запишет его в папку игры и повторно откроет записанный архив для проверки.
5. После сообщения об успешной установке запустите Dota 2 и откройте деморежим нужного героя. Игра читает новый пакет при запуске. Если вы включили или отключили моды либо поменяли их порядок, повторите шаги 4 и 5. В Rift Atelier отдельно видны текущий выбор для профиля и состояние последней установки.

## Свои файлы

| Файл | Что учитывает импорт |
| --- | --- |
| PNG, JPG, JPEG, TGA | До 4096 × 4096. Приложение сохраняет каналы RGBA и строит уменьшенные уровни текстуры. Для перекраски выбирайте цветовую карту, обычно с `color` в пути. Карты нормалей, маски и текстуры со специальной упаковкой каналов лучше импортировать как подготовленные `.vtex_c`. |
| WAV | PCM 8 или 16 бит, моно или стерео, до 65 535 Гц. Подойдут 44,1 и 48 кГц. Импорт создаёт `.vsnd_c` без точек зацикливания. |
| VMDL | Выберите модель из проекта `content/dota_addons/<аддон>/models/`. Компилятор Workshop Tools использует её FBX, материалы и другие зависимости по исходным путям. Для переноса модели с собственными материалами удобнее собрать VPK, включив все зависимые ресурсы. |
| Готовые ресурсы | Поддерживаются `.vtex_c`, `.vmat_c`, `.vmdl_c`, `.vsnd_c`. Выбирайте игровой файл того же типа. |
| VPK, ZIP | Принимаются самостоятельные VPK и ZIP с такими пакетами. Отдельные части многотомного VPK не поддерживаются. |

Для FBX сначала создайте модель в ModelDoc, привяжите скелет и материалы, затем сохраните VMDL. Workshop Tools включаются в Steam в свойствах Dota 2, в разделе дополнительного контента. [Инструкция Steam](https://help.steampowered.com/en/faqs/view/0CCF-571A-4430-0130) · [Исходники героев и требования Valve](https://www.dota2.com/workshop/requirements/?l=russian)

## Импорт с диска

Нажмите «Импортировать» или одну из карточек «Текстура», «Модель», «Звук». В каждом из этих диалогов видны ZIP и VPK. Для нескольких файлов удерживайте Ctrl при выборе. Можно также перетащить файлы из Проводника прямо в приложение.

В каталоге кнопка «Мои загрузки» показывает завершённые VPK и ZIP с пакетами из системной папки «Загрузки». Файл из другой папки можно указать вручную. Если у ZIP размер **0 Б**, в нём нет данных модели. Скачайте его заново через каталог или по прямой ссылке и дождитесь завершения. Переименование такого файла не восстановит содержимое.

## Картинки в библиотеке

Нажмите на ресурс, чтобы открыть его сведения. При импорте программа ищет картинку в ZIP, изображение рядом с исходным файлом или подходящую картинку внутри VPK. Под предпросмотром указано, откуда он взят. Игровая иконка показывает предмет, а исходная текстура — раскладку поверхности. Для точного вида модели в игре нажмите «Прикрепить скриншот…» или «Заменить картинку…» и выберите собственный PNG, JPEG или WebP. Обложка сохраняется в библиотеке и не попадёт в игровой пакет.

Портрет выбранного героя загружается с CDN Valve и сохраняется на диске. На главной странице нажмите «Выбрать героя», чтобы посмотреть один из шести исходных обликов Valve. Вид конкретной модификации показан в её авторской карточке в каталоге. [Outworld Destroyer](https://www.dota2.com/hero/outworlddestroyer) · [Dawnbreaker](https://www.dota2.com/hero/dawnbreaker) · [Queen of Pain](https://www.dota2.com/hero/queenofpain) · [Juggernaut](https://www.dota2.com/hero/juggernaut) · [Lifestealer](https://www.dota2.com/hero/lifestealer) · [Brewmaster](https://www.dota2.com/hero/brewmaster)

Если мод заменяет только материал или текстуру, проверьте цвет, блеск и детали поверхности героя в деморежиме. Форму модели меняет пакет с новой геометрией.

## Установка и отмена

Приложение записывает один объединённый VPK в свободный слот в `game/dota_russian`, `game/dota_koreana` или `game/dota_schinese`. Папка должна существовать, а выбранный в приложении язык озвучки должен совпадать с русской, корейской или упрощённой китайской озвучкой Dota 2. Если в конфигурации игры есть параметр `AudioLanguage`, Rift Atelier сверяет его перед записью. Сообщение о несовпадении подскажет, какую озвучку проверить. Для другой озвучки можно экспортировать профиль как отдельный VPK. Другие установленные моды, меняющие те же ресурсы, могут повлиять на результат.

Чтобы отменить установку, закройте игру и в настройках нажмите «Снять профиль». Rift Atelier проверит свой пакет по контрольной сумме и удалит его. Можно снова применить прежний профиль из библиотеки. При несовпадении контрольной суммы приложение остановит снятие и покажет сообщение.

Библиотека, исходники для предпросмотра и состав профилей хранятся в `%LOCALAPPDATA%\RiftAtelier`. Для резервной копии закройте приложение и скопируйте эту папку.

## Сборка из исходников

На Windows x64 установите Rust stable с инструментарием MSVC и компоненты C++ Build Tools. Откройте PowerShell рядом с `Cargo.toml` и выполните команду. [Установка Rust](https://www.rust-lang.org/tools/install)

```powershell
cargo build --release --locked
```

Готовый файл — `target\release\rift-atelier.exe`.
